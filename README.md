# Wubzy's Words of Wonder Generator

Fill in the blanks, make a card and discover a surprise after five cards.

## How it's built

- `index.html` + `card.js` + `style.css` = Wubzy's Greeting Card Generator
- `scripts/` folder contains `madlibs-working.js`  `madlibs.js`  `pause.js`  `tick.js`
